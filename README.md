# Oreslang FPGA platform (experimental)

Board/toolchain workflows for RTL emitted by `oreslang-source.hdl`: simulation, synthesis, placement-and-routing and eventual hardware verification. Does not implement the Oreslang language/compiler. FPGA bitstreams and board results must be evidenced separately. See https://github.com/ores-truffle-oreslang/oreslang-common-source/pull/65.
